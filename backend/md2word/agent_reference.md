# MD2Word Agent Reference

## 允许语法

### 标题

```md
# 文档标题
## 一级章节
### 二级小节
#### 三级小节
```

### 普通段落

```md
这是一个普通段落。
这是包含 `inline code` 的普通段落。
```

### 无序列表

```md
- 列表项一
- 列表项二
  - 子项一
```

### 有序列表

```md
1. 第一步
2. 第二步
```

### 引用

```md
> 普通引用
> 提示：提示内容
> 注意：注意内容
> 警告：警告内容
```

### 表格

```md
表 1 示例表格
| 列1 | 列2 |
| --- | --- |
| A | B |
```

### 图片

```md
![示意图](images/example.png)
```

### 代码块

````md
```python
print("hello")
```
````

## 示例模板

```md
# 文档标题

## 一级章节一

这是一级章节一的正文内容。

### 二级小节一

这是二级小节一的正文内容。

### 二级小节二

- 列表项一
- 列表项二

## 一级章节二

这是一级章节二的正文内容。

### 二级小节一

表 1 示例表格
| 列1 | 列2 |
| --- | --- |
| A | B |
```
