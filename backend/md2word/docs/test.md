# 石墨烯带电捕碳技术软件（第二本）软件说明书

## 1. 软件概述

石墨烯带电捕碳技术软件（第二本）是一套面向单次仿真任务的 Web 应用。软件通过浏览器页面接收带电石墨烯捕碳计算所需的输入参数，在后端创建一次独立的仿真会话，并在同一任务链路内提供状态显示、结果分析和结果导出功能。软件的页面结构、接口组织和结果展示方式均围绕一次仿真任务展开。

本软件的运行范围固定为单次、一次性、无持久化归档的仿真链路。当前版本不包含登录、用户权限、项目空间、历史任务归档、服务重启后的任务恢复和长期数据库存储能力。软件在当前版本中只处理一组输入参数对应的一次仿真计算，并在当前服务进程存活期间对该任务的状态、结果摘要、时间序列和可视化帧提供读取能力。

本软件的主要使用对象为需要通过浏览器页面完成带电石墨烯捕碳参数配置、运行观察和结果查看的研究或工程使用人员。软件的使用方式为页面输入、接口提交、后台计算和页面读取结果，不要求使用者安装单独桌面客户端。

## 2. 软件功能说明

### 2.1 首页

首页用于显示软件名称、软件入口以及与业务范围对应的功能概览。该页面承担软件说明和流程引导作用，不承担历史任务展示、会话归档管理或用户身份展示功能。

页面由页眉区域、三维演示区域、核心功能说明区域、使用流程区域和开始仿真按钮区域组成。页眉区域提供软件标题、语言切换入口和开始仿真入口。三维演示区域用于表示带电石墨烯基底、游离 CO2 和已捕获 CO2 的相对位置关系。核心功能说明区域用于说明软件在输入组织、运行监控和结果分析方面的能力边界。使用流程区域用于说明一次仿真任务从配置到结果导出的页面顺序。

当前状态下，首页不加载历史任务列表，也不显示登录或用户身份信息。页面底部的开始仿真按钮直接进入参数配置页面，当前页面内不执行任务提交操作。

用户可在首页执行语言切换操作，也可通过开始仿真按钮进入仿真配置流程。首页中的说明信息不写入仿真会话，也不影响后续计算结果。


### 2.2 仿真配置页面

仿真配置页面用于输入一次带电石墨烯捕碳仿真任务所需的公开参数。该页面是一次任务的唯一参数入口，提交成功后，当前输入参数即形成该次仿真的公开输入定义。

页面由页眉区域、参数输入区域和提交摘要区域组成。参数输入区域按环境条件、力场模型、时间积分和石墨烯捕获几何四组进行组织。每组参数内部按字段名称、单位和数值输入框排列。提交摘要区域用于显示 CO2 粒子数、背景粒子数和运行时长等派生结果。页面底部提供开始仿真按钮。

当前状态下，页面使用默认参数作为初始值。输入框支持数值修改，前端页面会对必填项、数值格式和部分范围条件执行本地校验，后端接口负责最终约束校验。当页面存在无效输入时，本地提交会被阻止，对应字段显示错误信息。

用户完成参数输入后，可通过开始仿真按钮提交任务。提交成功后，页面跳转至监控页面；提交失败时，页面保留当前输入值，并显示对应错误信息。


### 2.3 石墨烯捕获几何参数区域

石墨烯捕获几何参数区域用于输入石墨烯尺寸和捕获判定阈值。该区域定义石墨烯平面几何范围以及粒子进入近表面或已捕获状态时所依据的判定条件。

该区域由石墨烯宽度、石墨烯高度、捕获距离、速度阈值和驻留步数等输入项组成。石墨烯宽度和石墨烯高度用于确定捕获平面的有效尺寸。捕获距离、速度阈值和驻留步数用于判定粒子在仿真运行过程中是否满足近表面或已捕获条件。

当前状态下，区域内各输入项显示默认值。页面与其他参数分组保持一致的数值输入方式，并在字段附近显示单位信息。

用户可在该区域修改几何和判定条件，以形成新的仿真输入组合。该区域中的值参与后续结果摘要和三维可视化中的捕获状态计算。

### 2.4 监控页面

监控页面用于显示一次仿真任务的生命周期状态和运行进度。该页面是仿真提交后的主要状态查看页面，用于读取当前仿真会话在后端中的执行结果。

页面由页眉区域、状态摘要区域、进度显示区域、关键统计区域和时间信息区域组成。页眉区域提供页面切换按钮。状态摘要区域显示仿真状态。进度显示区域显示当前步数和总体进度。关键统计区域显示 CO2 粒子数、背景粒子数和运行时长。时间信息区域显示创建时间、开始时间和完成时间。当前页面不承担结果导出功能。

当前状态下，当仿真已结束时，页面显示完成状态，并允许进入分析页面。当仿真仍在运行时，页面显示对应的运行状态和累计进度；当仿真尚未启动时，页面显示创建后的初始状态。

用户可在该页面查看当前仿真状态，并在任务完成后进入分析页面或三维粒子页面。监控页面中的状态字段与时间字段来源于后端公开会话对象。


### 2.5 分析页面

分析页面用于显示已完成仿真任务的摘要指标、图表结果、场视图和导出入口。该页面面向已经完成的任务结果，不承担任务提交和运行进度轮询功能。

页面由页眉区域、结果摘要区域、摘要指标区域、时序图表区域、场视图区和导出操作区域组成。结果摘要区域显示捕获效率、已捕获 CO2 数量和剩余 CO2 数量。摘要指标区域显示平均动能、平均速度、表面占据率、近表面 CO2、完成步数和运行时长。时序图表区域显示采样点的变化趋势。场视图区显示场切片及其控制项。导出操作区域提供 JSON 和 CSV 两种导出方式。

当前状态下，分析页面只对已完成仿真开放。页面读取当前进程内的结果摘要、时序点和场帧数据，不依赖长期归档记录。若当前仿真未完成，分析页面不进入正式结果显示状态。

用户可在该页面查看指标、图表和场视图，并导出当前仿真结果。分析页面展示的数据属于当前仿真会话在当前进程中的可读取结果集。


### 2.6 分析图表区域

分析图表区域用于显示仿真过程中捕获效率、表面占据率和近表面 CO2 的变化趋势。该区域属于分析页面中的二维结果视图部分。

该区域由图表标题、图例、坐标轴和折线图组成。图表数据来源于时序采样点，每个采样点表示一次采样时刻的聚合统计值，而不是单粒子轨迹。折线图用于表示采样点随步数或仿真时间变化时的统计结果。

当前状态下，图表以折线方式显示指标变化。图例位于图表区域内部，用于区分各统计项。图表显示内容与结果摘要中展示的统计量属于同一任务结果的不同表现形式。

用户可在该区域查看仿真过程中各统计量的变化趋势，并据此判断采样点之间的变化情况。


### 2.7 场视图区域

场视图区域用于显示与仿真帧对应的场切片和相关控制项。该区域属于分析页面中的三维场结果视图部分。

该区域由切片方向切换、切片索引控制、切片叠加半径控制、等值面阈值控制、矢量采样步长控制和场视图显示区域组成。场视图与粒子帧共享相同的采样步和仿真时间，因此页面中的场视图与粒子可视化在时间轴上保持对应关系。

当前状态下，页面可在同一场景中组合显示切片、等值面和电场矢量。可视化数据来自当前仿真会话对应的场帧接口，网格尺寸由后端运行配置决定。

用户可在该区域调整切片方向和显示参数，以查看不同层面的场分布。该区域不直接修改仿真计算结果，只改变当前页面中的显示方式。


### 2.8 三维粒子页面

三维粒子页面用于显示粒子帧的真实三维分布。该页面面向单个采样帧的空间状态展示，用于补充监控页和分析页中以摘要形式呈现的结果。

页面由页眉区域、三维视图区和图例区域组成。三维视图区显示石墨烯平面、背景粒子、未捕获 CO2 和已捕获 CO2 的空间位置。图例区域用于区分不同粒子类型。页眉区域提供返回监控页和进入分析页的页面切换入口。

当前状态下，页面显示当前仿真帧的三维粒子分布。粒子帧包含该帧中全部模拟粒子，而不是只返回 CO2 子集。已捕获 CO2 和未捕获 CO2 在视图中分别以不同视觉形式表示，背景粒子与 CO2 粒子保持区分。

用户可在该页面查看当前粒子空间分布，并返回监控页或进入分析页。该页面本身不提供结果导出操作。


## 3. 软件运行环境

本软件采用浏览器访问方式运行。客户端通过浏览器访问前端服务地址进入软件页面。软件界面支持中文和英文两种语言显示，语言状态由浏览器本地存储记录。

客户端环境要求如下：

- 具备图形界面显示能力的操作系统
- 支持现代 Web 标准的浏览器
- 可访问前端服务地址与后端接口地址

服务端环境由前端服务和后端服务组成。前端项目采用 Vite、React 和 TypeScript 构建，页面使用 Tailwind、shadcn 组件和数据可视化依赖完成界面与图表渲染。后端服务采用 FastAPI 提供 HTTP 接口，使用 Pydantic 进行模式校验，使用 NumPy 执行数值计算。后端当前运行模型为进程内会话注册表加本地后台 worker。

本软件不要求数据库作为运行前提。当前版本的仿真会话、结果摘要、时间序列和三维可视化帧均保存在当前服务进程内存中。服务端接口前缀为 `/api`，前端通过 HTTP 调用后端公开接口。

## 4. 软件操作流程

本软件围绕单次仿真任务展开，流程按照页面进入顺序执行。整个操作过程以一次输入定义、一条运行链路和一次结果读取为基本单位。

1. 用户进入首页，查看软件用途、功能说明和使用流程，并通过开始仿真按钮进入配置页面。
2. 用户在仿真配置页面填写环境条件、力场模型、时间积分和石墨烯捕获几何参数。
3. 用户提交一次仿真请求，系统创建仿真会话，并进入监控页面。
4. 用户在监控页面查看任务状态、运行进度、统计摘要和时间信息。
5. 仿真完成后，用户进入分析页面查看摘要指标、时序图表和场视图。
6. 用户按需要进入三维粒子页面查看粒子空间分布。
7. 用户在分析页面导出 JSON 或 CSV 结果。

## 5. 软件输入与输出

本软件输入内容为一次仿真任务的参数集合。输入参数包括环境条件、力场模型、时间积分参数和石墨烯捕获几何参数。输入值以页面表单方式提交到后端接口。输入项均采用数值形式，并带有对应的单位语义。一次提交形成一次独立的仿真请求。

输入参数的主要分组如下：

- 环境条件：温度、压力、粒子数、CO2 比例
- 力场模型：LJ epsilon、表面电荷密度、电场强度
- 时间积分：时间步长、总步数、采样间隔
- 石墨烯捕获几何：石墨烯宽度、石墨烯高度、捕获距离、速度阈值、驻留步数

本软件输出内容包括运行状态、进度信息、结果摘要、时序图表数据、三维粒子帧、场帧和导出文件。结果输出以页面显示和文件导出两种方式提供。页面显示用于当前会话内查看，文件导出用于将结果以标准格式保存到浏览器侧下载文件中。

页面输出范围包括：

- 仿真状态与时间戳
- 捕获效率、已捕获 CO2、剩余 CO2 等摘要指标
- 时序折线图
- 场切片与等值面控制视图
- 三维粒子空间分布视图

文件输出范围包括：

- JSON 结果文件
- CSV 结果文件

JSON 导出用于保留结构化结果数据，CSV 导出用于保留表格化结果内容。两种导出方式均来自当前仿真会话的内存结果，而不是来自历史档案。

## 6. 软件特点

### 6.1 单次仿真任务模式

本软件采用单次任务模式组织页面和接口。一次页面流程只围绕一组参数、一次仿真会话和一次结果输出展开。软件不提供多任务工作台、项目归档或任务历史中心，因此页面结构和接口设计均保持在单任务范围内。

### 6.2 进程内结果可见性

本软件的运行状态、时间序列、结果摘要、粒子帧和场帧在当前服务进程生命周期内可读。服务重启后，旧 `simulation_id` 默认失效。该行为属于当前版本的系统边界，而不是持久化能力。页面中的监控信息、分析信息和可视化帧均以当前进程内保留的数据为依据。

### 6.3 二维图表与三维视图并行提供

本软件同时提供基于时序采样点的二维图表和基于粒子帧、场帧的三维视图。二维图表用于显示聚合统计值变化，三维视图用于显示真实空间分布和场采样结果。两类结果由不同接口提供，但都对应同一仿真会话。

## 7. 数据管理与访问方式

本软件当前版本为无登录、无权限控制的工具型 Web 应用。所有公开 API 都为无认证接口。软件不实现用户隔离、资源归属判定或角色控制。前端页面在当前版本中不区分操作者身份。

本软件不依赖长期持久化数据库保存业务数据。仿真任务、结果摘要、时间序列和可视化帧在当前进程内保存。当前版本不以历史归档为公开能力，也不以服务重启后的数据恢复为公开能力。任务完成后，数据仍可在当前进程内短时可读，但该保留不构成持久化保存承诺。

本软件提供 JSON 与 CSV 导出能力。导出内容来自当前会话的内存数据，而不是外部档案系统。浏览器页面对语言选择使用本地存储记录，但该记录不属于仿真业务数据。
